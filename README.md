# ⚽ Captain Tsubasa 2: Super Striker — Tradução Independente PT-BR

Seja bem-vindo(a) ao projeto de tradução independente e não oficial para o **Captain Tsubasa 2 World Champions!** 

Como este é o meu primeiro trabalho de tradução de jogos, estou aprendendo todo o processo do zero (engenharia reversa, romhacking e adaptação de textos). 

---

## 🛠️ Como o projeto é feito
*   **Tradução Base:** Os textos estão sendo traduzidos inicialmente com o auxílio de Inteligência Artificial.
*   **Refinamento:** Passo horas jogando e testando diretamente no jogo para garantir que as falas façam sentido dentro do contexto de cada partida.

---

## 🤝 Como contribuir?
Como ainda estou aprendendo, a ajuda da comunidade é fundamental! Você pode colaborar de duas formas:

1.  **Revisão e Testes:** Jogue a versão atual, encontre erros de digitação, termos fora de contexto ou textos cortados e abra uma *Issue* aqui no GitHub.
2.  **Sugestões:** Ideias de melhores termos para nomes de técnicas ou diálogos são super bem-vindas.
